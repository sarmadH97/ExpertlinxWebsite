# ExpertLinx Website

The ExpertLinx marketing website, built with Next.js and optimized for deployment on Vercel.

## Local development

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run typecheck
npm run build
```

SEO support includes server-rendered content, canonical metadata, Open Graph and Twitter cards, structured data, `robots.txt`, and `sitemap.xml`.
